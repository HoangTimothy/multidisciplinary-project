\begin{frame}{Kết quả benchmark}
  \scriptsize
  \begin{columns}[T,onlytextwidth]
    \column{0.48\textwidth}
    \begin{block}{Dataset và tune}
      \begin{itemize}
        \item 500 ảnh public từ COCO val2017 và BDD100K validation.
        \item Label set: \texttt{person}, \texttt{vehicle}, \texttt{static\_obstacle}.
        \item Winner config: \texttt{tuned\_lite0\_int8\_high\_recall}.
        \item Tuned params cốt lõi: \texttt{SCORE\_THRESHOLD = 0.35}, \texttt{MAX\_RESULTS = 15}, \texttt{INFER\_EVERY\_N\_FRAMES = 5}, denoise + low-light.
      \end{itemize}
    \end{block}
    \column{0.52\textwidth}
    \begin{block}{Số liệu chính}
      \begin{itemize}
        \item Public 500 ảnh COCO+BDD: alert correctness 0.812, p95 31.4 ms.
        \item Lite2 int8: alert correctness 0.842, p95 84.7 ms.
        \item Synthetic robustness: risk alert correctness 0.827, p95 35.6 ms.
      \end{itemize}
    \end{block}
    \begin{exampleblock}{Ghi chú}
      Benchmark này là public dataset + synthetic robustness. FPS và server-side alert latency vẫn cần đo trên Raspberry Pi; full camera-to-audio end-to-end latency cần instrumentation riêng.
    \end{exampleblock}
  \end{columns}
\end{frame}

\begin{frame}{Những chỉ số còn phải benchmark thật}
  \footnotesize
  \begin{block}{Cần benchmark thật}
    \begin{itemize}
      \item FPS trung bình trên Raspberry Pi hoặc máy demo thật.
      \item Độ trễ server-side alert từ frame vào đến cảnh báo.
      \item Độ ổn định stream trên LAN và ngrok.
      \item False alert trên frame âm tính.
      \item Độ trễ TTS khi phát từ browser hoặc engine offline.
    \end{itemize}
  \end{block}

  \begin{exampleblock}{Ghi chú trình bày}
    Không suy diễn benchmark public dataset thành runtime thật. Nếu cần full camera-to-audio end-to-end latency, phải đo bằng instrumentation hoặc video sync riêng.
  \end{exampleblock}
\end{frame}
